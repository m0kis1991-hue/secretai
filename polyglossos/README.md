# Πολύγλωσσος — Γλώσσες & Λόγος

Εφαρμογή εκμάθησης γλωσσών για κινητό (PWA) που τρέχει **εξ ολοκλήρου τοπικά**: χωρίς λογαριασμό, χωρίς server, χωρίς διαφημίσεις. Όλη η πρόοδος αποθηκεύεται στη συσκευή.

**Προεγκατεστημένες γλώσσες:** 🇬🇧 Αγγλικά · 🇫🇷 Γαλλικά · 🇪🇸 Ισπανικά · 🇮🇹 Ιταλικά · 🇩🇪 Γερμανικά · 🇬🇷 Ελληνικά (για μητρικούς ομιλητές: εκφορά λόγου & λόγιο λεξιλόγιο).

## Πώς τη βάζεις στο κινητό

Η εφαρμογή είναι στατικά αρχεία. Χρειάζεται να «σερβιριστεί» **μία φορά** μέσω `https://` ή `localhost` ώστε να εγκατασταθεί· μετά δουλεύει offline.

### Επιλογή Α — Δημοσίευση (προτείνεται, 2 λεπτά)
1. Ανέβασε τον φάκελο `polyglossos/` σε στατική φιλοξενία (Vercel με Root Directory = `polyglossos`, GitHub Pages ή Netlify Drop).
2. Άνοιξε το URL στο κινητό:
   - **Android (Chrome):** μενού ⋮ → «Εγκατάσταση εφαρμογής».
   - **iPhone (Safari):** Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
3. Από εκεί και πέρα ανοίγει σαν κανονική εφαρμογή και δουλεύει χωρίς internet. Τα δεδομένα σου **δεν** φεύγουν από το κινητό.

### Επιλογή Β — 100% τοπικά σε Android (Termux)
```bash
pkg install python git
git clone <αυτό το repo> && cd secretai/polyglossos
python serve.py
```
Άνοιξε στο Chrome `http://localhost:8000` → «Εγκατάσταση εφαρμογής». Μετά την εγκατάσταση δεν χρειάζεται να τρέχει ο server.

### Επιλογή Γ — Από υπολογιστή (μόνο για δοκιμή)
`python3 serve.py` και άνοιγμα `http://localhost:8000`. Από το κινητό μέσω `http://<IP-υπολογιστή>:8000` η εφαρμογή ανοίγει, **αλλά** ο browser μπλοκάρει μικρόφωνο, offline λειτουργία και εγκατάσταση (απαιτούν https ή localhost).

## Τίμιοι περιορισμοί

- **Αναγνώριση φωνής:** στα περισσότερα κινητά (Chrome/Android, Safari/iOS) γίνεται από servers της Google/Apple — χρειάζεται internet. Χωρίς αυτήν, οι ασκήσεις ομιλίας γίνονται με αυτοαξιολόγηση και το εργαστήριο λόγου ηχογραφεί για να ακούσεις τον εαυτό σου.
- **Φωνές εκφώνησης:** χρησιμοποιούνται οι φωνές του κινητού. Αν λείπει κάποια γλώσσα: Android → Ρυθμίσεις → Γλώσσες → Μετατροπή κειμένου σε ομιλία· iPhone → Προσβασιμότητα → Εκφώνηση περιεχομένου → Φωνές.
- **Όγκος περιεχομένου:** 390 λέξεις και 98 προτάσεις ανά γλώσσα (A1–C1) είναι γερός πυρήνας, όχι πλήρες πρόγραμμα C2. Η αρχιτεκτονική επιτρέπει να προστεθεί περιεχόμενο χωρίς αλλαγή κώδικα (βλ. παρακάτω).
- **Τα δεδομένα ζουν στον browser.** Αν καθαρίσεις τα δεδομένα του browser, χάνονται — κάνε αντίγραφο από τις Ρυθμίσεις.

## Παιδαγωγικός σχεδιασμός

1. **Ενεργή ανάκληση** αντί για παθητική ανάγνωση: κάθε νέα λέξη παρουσιάζεται και ελέγχεται 2–4 βήματα αργότερα.
2. **Από την αναγνώριση στην παραγωγή:** μέχρι τη 2η σωστή απάντηση οι ασκήσεις είναι επιλογής· μετά γίνονται γραφή, υπαγόρευση, ομιλία.
3. **Ανάμειξη (interleaving):** νέα + επαναλήψεις + γραμματική στην ίδια συνεδρία.
4. **Λάθη = ευκαιρία:** ό,τι απαντάς λάθος ξαναρωτιέται σε 3 βήματα με διαφορετικό τύπο άσκησης.
5. **Προφίλ μάθησης χωρίς μύθους:** η έρευνα δεν στηρίζει τη μάθηση «μόνο με ένα στυλ». Το προφίλ αλλάζει την αναλογία των ασκήσεων, ποτέ δεν αποκλείει τρόπο (ελάχιστο 12% ο καθένας).

## Δομή

```
polyglossos/
├── index.html, manifest.webmanifest, sw.js   PWA + offline
├── css/app.css                                Mobile-first, φωτεινό/σκοτεινό θέμα
└── js/
    ├── data/vocab.js       Κοινός πίνακας εννοιών: 'ελ|en|fr|es|it|de|emoji' + προτάσεις
    ├── data/grammar.js     Γραμματική ανά γλώσσα & επίπεδο
    ├── data/placement.js   Ερωτήσεις κατάταξης + τεστ μητρικών ελληνικών
    ├── data/greek.js       Λόγιο λεξιλόγιο, εκφράσεις, λάθη, παρώνυμα, ρητορική
    ├── core.js             Αποθήκευση, SRS, φωνή (TTS/αναγνώριση), έλεγχος απαντήσεων
    ├── content.js          Ευρετήριο, πρόοδος ενοτήτων, αντιπερισπασμοί
    ├── exercises.js        Οι τύποι ασκήσεων
    ├── session.js          Σύνθεση μαθήματος & εκτέλεση συνεδρίας
    ├── tests.js            Τεστ προφίλ & κατάταξης
    ├── speechlab.js        Εργαστήριο λόγου & ανάλυση ομιλίας
    ├── screens.js          Οθόνες
    └── app.js              Δρομολόγηση
```

**Προσθήκη λέξεων:** πρόσθεσε γραμμές στο `vocab.js` στη μορφή `'ελληνικά|english|français|español|italiano|deutsch|emoji'` (τα ουσιαστικά με άρθρο). Τα IDs παράγονται από το περιεχόμενο, οπότε η πρόοδος των υπαρχουσών λέξεων δεν επηρεάζεται. Μετά άλλαξε το `CACHE` στο `sw.js` (π.χ. `polyglossos-v2`) ώστε τα κινητά να πάρουν την ενημέρωση.
